# Agent Note: 缩窄会话滚动条

Status: implemented

[English](2026-08-15-conversation-scrollbar-width.md) | 中文

## 问题

主会话滚动条此前使用主题共享的 8px 宽度。当前客户端需要右侧会话滚动条缩窄 30%，同时保持覆盖式输入框与会话滚动区域的间距对齐。

## 决策

会话滚动容器和独立聊天滚动回退容器的 WebKit 滚动条宽度都设置为主题共享宽度的 70%。当前主题宽度为 8px，因此实际显示宽度为 5.6px。覆盖式输入框座位的右侧补偿使用相同的 70% 计算。工作区侧边栏和全局主题滚动条继续保持 8px。

## 曾考虑的替代方案

**修改全局滚动条宽度。** 否决：这会同时改变工作区侧边栏及其他不在本次范围内的滚动容器。

**只修改滚动条伪元素。** 否决：覆盖式输入框座位仍会按照原有滚动槽宽度补偿，可能与会话内容产生横向偏移。

**在每条会话规则中直接写入 5.6px。** 否决：从主题共享宽度计算局部值，可以在共享宽度后续调整时继续保持 30% 的比例关系。

## 后果

主会话右侧滚动条会明显缩窄，侧边栏和其他无关滚动容器保持原有宽度。覆盖式输入框的右侧补偿与新的计算宽度保持一致。标准滚动条路径仍由现有主题回退规则控制，本次调整针对 WebKit 滚动条显示路径。

## 测试

会话测试与滚动条契约测试合计 28 个测试文件、438 项测试全部通过。`pnpm run build:lib:client` 构建通过。
