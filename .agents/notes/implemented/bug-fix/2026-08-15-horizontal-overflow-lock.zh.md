# Agent Note: 固定客户端横向位置

Status: implemented

[English](2026-08-15-horizontal-overflow-lock.md) | 中文

## 问题

当子视图或视觉效果超出窗口宽度时，DSH 窗口可能发生横向移动。客户端需要固定横向位置，同时保留会话内容的纵向滚动。

## 决策

Web 壳在 `html`、`body` 和 `#root` 上统一设置 `overflow-x: hidden` 与 `overscroll-behavior-x: none`。会话级滚动区域继续保留自身的裁剪规则，因此全局规则可以关闭窗口级横向移动，同时不改变代码面板和数据面板中有明确边界的局部横向滚动。

## 曾考虑的替代方案

**只修改会话滚动区域。** 否决：剩余的横向移动可能来自文档视口或其他壳层子节点。

**对整个应用设置 `overflow: hidden`。** 否决：这会同时移除会话所需的纵向滚动路径。

**删除所有内部横向溢出规则。** 否决：有边界的代码面板和数据面板仍可能需要局部横向查看，且不应带动整个客户端。

## 后果

客户端视口会固定在横向位置。会话内容仍可纵向滚动，有边界的内部面板继续保留自身的溢出行为。

## 测试

基础样式契约测试通过，共 4 项测试。`pnpm run build:lib:client`、`pnpm run build:web` 和 `git diff --check` 均通过。已重启实际运行的 DSH 客户端并执行向右滚动测试，窗口没有发生横向位移。
